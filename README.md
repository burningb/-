# 함께하는 기록

김종훈 작가의 첼로 소리와 그림으로 만든 웹 체험 작품입니다. 강원문화재단 《함께 젓는 노, 감각의 데이터 항해기》 연출 시안으로 제작했습니다.

## 세 장

| 장 | 내용 |
|---|---|
| 01 진동 | 작가의 악보 그림(칸)을 누르면 첼로 연주1의 낮은 소리가 한 토막씩 울리고, 첼로를 켜는 피규어가 그 칸 아래로 갑니다. |
| 02 흐름 | 첼로 연주2의 활 한 번이 파스텔 띠 하나가 되어 쌓이고, RC카가 그 위에 바퀴 궤적을 남깁니다. 화면을 문지르면 직접 운전할 수 있습니다. |
| 03 항해 | 노를 저을 때마다 첼로가 한 번 활을 긋습니다. 1,000번이 모이면 작가가 그린 시드니 오페라하우스에서 오케스트라와 함께 공연이 열립니다. |

## 실행

브라우저가 오디오와 JSON을 불러와야 하므로 로컬 서버로 엽니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속 후 "소리 켜고 시작"
```

GitHub Pages로 배포해도 그대로 동작합니다.

## 알아둘 점

- 03 항해의 "모든 관람객의 노 젓기 합산"은 Claude 아티팩트의 공유 저장소 기능으로 동작합니다. 이 저장소 버전에서는 각자 브라우저 안에서만 셉니다. 공개 배포에서 합산이 필요하면 별도 서버나 DB(예: Firebase, Supabase)를 붙여야 합니다.
- 로컬에서는 "도착 장면 미리 보기" 버튼이 항상 보입니다.
- 소리는 휴대폰 녹음, 그림은 작품 사진입니다. 본편에서는 퍼포먼스 당일 소스로 교체합니다.

## 파일

- `index.html`: 페이지 전체 (HTML, CSS, JS 한 파일)
- `score.jpg`, `opera.jpg`: 작가의 악보 그림, 시드니 오페라하우스 그림
- `fig1.png`, `fig2.png`, `rc.png`: 피규어와 RC카 이미지
- `cells.mp3`: 01 진동의 56개 칸 소리 (첼로 연주1에서 활이 울리기 시작하는 지점부터 잘라 모은 것)
- `cello2.mp3`: 첼로 연주2 전곡
- `sound.json`: 녹음에서 뽑은 활 단위 구간, 음높이, 음량 데이터
- `sound_data.py`: `sound.json`을 만드는 스크립트
- `bow_and_wheel_video.py`: 같은 데이터로 영상 《활과 바퀴》를 렌더링하는 스크립트

## 권리

`assets/`의 그림, 피규어 이미지, 첼로 녹음은 김종훈 작가의 작품과 자료입니다. 저장소는 비공개로 두고, 공개나 재사용은 작가 측 허락을 받은 뒤에 하십시오.
